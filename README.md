## Purpose
This repository was created as part of the SWE 442 – Version Control and Change Management assignment. Its purpose is to demonstrate the use of GitHub for software configuration management, including repository setup, branching, version control, change tracking, and collaboration through pull requests and issues.



## Change Control Process

Changes in this repository were managed using GitHub issues, branches, and pull requests. Issue #2, titled "Clarify Project Documentation", was created to track the required documentation improvements. A separate branch named "docs-update" was used to add the version control explanation. The changes were reviewed through Pull Request #1 before being merged into the main branch. This process helps ensure that changes are tracked, reviewed, and properly documented.
